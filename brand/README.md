# Mise Brigade de Repo Brand System

The graphic system is built around **Code Chef / Repository Stewardship**: dark operational surfaces, kitchen-brigade metaphors, terminal typography, and explicit visual semantics for inspection, authority, and verification.

## Semantic use

- Blue = inspect / route / observe.
- Gold = active work.
- Orange = write authority.
- Green = verified safe state.
- Red is reserved for hard failure or security incidents.

## Accessibility

Every SVG carries an accessible `aria-label`. Operational instructions must also remain available as Markdown text; graphics reinforce the documentation rather than replacing it.
